CV HTML de Younes AROUK — octobre 2026

CONTENU
- index.html : page d'accueil du CV.
- CV AROUK Younes.html : le même CV, avec le nom de votre ancien fichier.
Chaque fichier HTML fonctionne seul : la photo et les PDF sont intégrés.

POUR METTRE À JOUR VOTRE DÉPÔT YounesArouk/cv-web-
1. Décompressez l'archive sur votre PC.
2. Ouvrez votre dépôt sur GitHub.
3. Cliquez sur Add file, puis Upload files.
4. Déposez les deux fichiers HTML à la racine du dépôt.
5. Saisissez un message de commit, par exemple : Mise à jour du CV — octobre 2026.
6. Validez la modification dans GitHub.

Le fichier CV AROUK Younes.html remplace l'ancien fichier du même nom.
Le fichier index.html sert de page d'accueil lorsque GitHub Pages publie
la racine de la branche concernée.
Vous pouvez retrouver votre adresse dans Settings > Pages > Visit site.

MODIFIER LE CV PLUS TARD
Le contenu se trouve dans la balise main. Le style se trouve dans style.
Pour changer la photo, remplacez la valeur src de img class="portrait"
par le chemin de la nouvelle photo (par exemple photo.jpg), puis ajoutez
la photo au même emplacement. Les liens des PDF intégrés correspondent
à la version actuelle : ils doivent aussi être actualisés après une future
modification du contenu.
